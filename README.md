# Contador de Arremessos

App para contar arremessos e cestas a partir de vídeos de treino gravados no celular.
Roda no navegador (Chrome), sem servidor: o vídeo não sai do celular.

Abra: https://lnt66.github.io/Arremessos-/

- Conta arremessos e cestas pela bola, aro e tabela.
- Reconhece o corpo (MediaPipe): mão do arremesso, salto, altura da soltura, cotovelo e joelho.
- Modo noturno automático, som opcional, narração em português.
- Histórico, evolução, recordes e estatísticas detalhadas, salvos no próprio celular.
